# Sistema-de-cadastro-de-usu-rio-e-login.-
Um sistema simples de cadastro de usuário e login. 
Objetivo: criar um sistema simples de cadastro de usuário e login. 

- Rota para cadastrar usuário

- Rota para atualizar usuário

- Rota para deletar usuário

- Rota para login

- Rota para logout

Para usuário, usar esses campos: 

- Nome
- Data de nascimento
- Email
- Senha
